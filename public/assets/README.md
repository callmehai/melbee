# Ảnh, video, âm thanh

Chép file vào đúng thư mục, **đặt đúng tên như trong `src/data/*.js`** là trang tự dùng ảnh thật
(thay cho hình minh hoạ). Đường dẫn trong file dữ liệu tính từ `public/`.

```
images/hero/       ảnh nền đầu trang (hero.jpg) và khối liên hệ cuối trang (cta.jpg)
images/products/   ảnh sản phẩm (honey-01.jpg, …) — ảnh dọc 4:5
images/story/      ảnh phần giới thiệu & câu chuyện (intro-macro.jpg, story.jpg)
images/origin/     bản đồ & ảnh vùng nguyên liệu (map.jpg, mountain.jpg, flowers.jpg, beekeeping.jpg)
images/process/    5 ảnh quy trình (01-mua-hoa.jpg … 05-dong-chai.jpg)
images/lifestyle/  ảnh cách thưởng thức (water.jpg, tea.jpg, food.jpg, gift.jpg)
images/gallery/    ảnh thư viện (01.jpg … 08.jpg)
videos/            video nền hero (hero.mp4) — chỉ tải sau khi trang đã hiện
audio/             âm thanh (nếu cần sau này)
icons/             logo, icon
```

Nén ảnh trước khi đưa lên (≤ 400KB/ảnh, rộng 1600–2400px cho ảnh lớn).
